# aeh-skill-konflux

When asked to write Python code, follow these guidelines:

1. Always include a docstring for functions and classes
2. Handle edge cases explicitly with early returns
3. Use type hints for function parameters and return values
4. Keep functions focused on a single responsibility
5. Write idiomatic Python using list comprehensions where appropriate
